# Real CAPTCHA image sources

All 139 current photographs are original downloaded files, with no generated images or baked-in grid lines.

- 120 120×120 tile photos: https://github.com/hbcbh1999/recaptcha-dataset (MIT).
- 19 450×450 single-photo challenges: https://github.com/ssivakorn/reCAPTCHA-study (CC BY-NC 4.0).
- Every original URL and path is recorded in image-manifest.json.
- Original license texts are bundled with the source and in public/licenses. Site credits are available from the challenge's info panel.
- Tile photos live in public/assets/photos; full photographs live in public/assets/scenes.
- Google public reCAPTCHA styles were consulted at https://www.gstatic.com/recaptcha/releases/guXhH0v-XMxlzmbTwqkaT4i5/styles__ltr.css. The interface reproduces 80% selected-tile scaling, 32px corner checkmarks, 60px centered dynamic checkmarks, white gutters, and two-second fading replacements.

Retrieved October 8, 2026. No third-party CAPTCHA or classification API is used by this app. No CAPTCHA-protected service is solved or accessed by the game.
